# Landing Page Color Update - Brand Colors

## Color Replacement Guide

Replace all violet/purple/fuchsia colors with your brand orange color.

### Brand Color
```
rgb(217, 155, 98)  - Main orange
rgb(197, 135, 78)  - Darker shade for gradients
```

## Quick Replace Commands

Use your text editor's find-and-replace feature:

1. `from-violet-500` → `from-[rgb(217,155,98)]`
2. `to-purple-600` → `to-[rgb(197,135,78)]`
3. `to-purple-500` → `to-[rgb(197,135,78)]`
4. `text-violet-400` → `text-[rgb(217,155,98)]`
5. `text-violet-300` → `text-[rgb(217,155,98)]`
6. `bg-violet-500` → `bg-[rgb(217,155,98)]`
7. `bg-violet-400` → `bg-[rgb(217,155,98)]`
8. `border-violet-500` → `border-[rgb(217,155,98)]`
9. `shadow-violet-500` → `shadow-[rgb(217,155,98)]`
10. `via-purple-400` → `via-[rgb(207,145,88)]`
11. `to-fuchsia-400` → `to-[rgb(197,135,78)]`
12. `from-violet-600` → `from-[rgb(217,155,98)]`
13. `to-purple-600` → `to-[rgb(197,135,78)]`
14. `hover:from-violet-500` → `hover:from-[rgb(207,145,88)]`
15. `hover:to-purple-500` → `hover:to-[rgb(187,125,68)]`

After these changes, your landing page will use your consistent brand orange color throughout while maintaining all the same structure, content, and animations.
